# Prototype — 1-shot talking-head (InstantID → TTS → LatentSync)

**Goal:** prove the from-scratch loop end-to-end on ONE short shot before scaling.
Identity = InstantID (no-train face inject). Voice = Chatterbox clone (done).
Lip-sync = LatentSync on pod. Keep it cheap: 1 shot, ~12s, plain bg.

Fail-fast rule: get THIS one shot working start→finish before writing a full
multi-shot script.

---

## 1. Script (spoken line)  — PLACEHOLDER, swap freely

> "Hey — this is me, fully generated by AI. My face, my voice, none of it
> filmed. If this looks and sounds like the real thing, the pipeline works."

~32 words ≈ ~12s at normal pace. Keep 25–40 words for a 10–15s shot.

---

## 2. Shot 1 spec

| Field | Value |
|---|---|
| Duration | ~12 s |
| Aspect / res | 1:1 or 9:16; gen + sync at **512×512** (LatentSync native), upscale after |
| FPS | **25** (LatentSync requirement) |
| Framing | head-and-shoulders, centered, looking at camera |
| Background | plain neutral (soft grey / off-white) |
| Wardrobe | simple solid top |
| Lighting | soft front light, no harsh glare |

---

## 3. Stage C — InstantID: generate the keyframe (POD)

Input: `data/photos/profile.jpeg` (+ any extra refs).
Generate ONE still of you matching the shot spec. Mouth ideally **neutral/closed**
(LatentSync drives the mouth — don't bake in a smile).

**Positive prompt (draft):**
> portrait photo of a man, head and shoulders, looking at camera, neutral
> expression, mouth closed, soft studio lighting, plain light grey background,
> sharp focus, photorealistic, 50mm

**Negative prompt (draft):**
> teeth showing, open mouth, wide smile, glasses glare, blurry, low quality,
> distorted face, extra fingers, watermark, cartoon

Output: `prototype/out/keyframe.png`
Check: is it recognizably you? If not → more/cleaner ref photos, or escalate to
Flux LoRA.

---

## 4. Stage A — Voice (DONE, re-run with this line)

Run in chatterbox venv (local, ~13s):
```
envs/chatterbox/bin/python scripts/tts_chatterbox.py \
  --text "Hey — this is me, fully generated by AI. My face, my voice, none of it filmed. If this looks and sounds like the real thing, the pipeline works." \
  --voice data/voice/8e0df5f6-8abc-48fa-abc7-e45b823ec0e9.wav \
  --out prototype/out/line.wav
```
Note: Chatterbox outputs **24kHz**; LatentSync wants audio **16kHz** → resample
on pod (`ffmpeg -i line.wav -ar 16000 line_16k.wav`).

---

## 5. Stage D — LatentSync: animate + lip-sync (POD)

LatentSync needs a *video*, not a still. For a static talking-head, make a
still→clip first (hold keyframe for 12s @ 25fps), then relip:
```
ffmpeg -loop 1 -i prototype/out/keyframe.png -t 12 -r 25 \
  -vf scale=512:512 prototype/out/base.mp4
```
Then LatentSync(base.mp4 + line_16k.wav) → talking clip.
Params to tune: inference_steps 20–50 (quality), guidance_scale 1.0–3.0 (sync;
too high = jitter). Start steps=30, guidance=1.5.
Output: `prototype/out/talk.mp4`

> NOTE: a held still may look stiff (no head motion). If too dead, fallback =
> SadTalker (photo+audio→moving base) → LatentSync relip. SadTalker needs the
> `animate.py` corruption fixed first (git checkout).

---

## 6. Stage E — Compose (local, $0)

Mux final audio, trim, optional GFPGAN face-restore + RIFE interp:
```
ffmpeg -i prototype/out/talk.mp4 -i prototype/out/line.wav \
  -c:v copy -c:a aac -shortest prototype/out/final.mp4
```
