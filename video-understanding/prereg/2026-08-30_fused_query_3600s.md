# Pre-registration — fused-query replication on LongVideoBench 3600 s

**Written 2026-08-30, BEFORE the arm was run or any 3600 s fused number existed.**
Prompted by an external review (Codex, 2026-08-30) noting that the paper's
prompt-boundary result is measured on the 600 s bin only while the headline
claim concerns hour-long video.

## Motivation

On LongVideoBench-600 s (n=412) the fused query (question stem + answer options)
given to the LongCLIP scorer produced a level shift of +2.9 to +3.9 points for
every selector except FOCUS*. The paper currently generalises the prompt boundary
to long video, but 3600 s was never tested. If the effect is bin-specific, the
claim must stay explicitly one-bin.

## Single pre-registered contrast

Arm A: OMP, k=8, LongVideoBench 3600 s, scorer query = question **stem only**
       (already run; the existing stem arm is the paired comparator).
Arm B: OMP, k=8, LongVideoBench 3600 s, scorer query = **stem + options fused**,
       identical in every other respect.

Everything else held fixed: Qwen3-VL-8B-Instruct, subtitles OFF, batch_size=1,
greedy / temperature 0, LongCLIP scorer, 1 fps candidate pool, identical cached
frame embeddings, identical answerer prompt.

**H0:** Pr(correct | fused) = Pr(correct | stem), on the same 564 questions.

**Test:** exact two-sided McNemar on paired correctness. Report b, c, n, the
paired difference in percentage points, and a 95% CI on the difference. Single
contrast, alpha = .05, no correction (only one test is pre-registered here).

**Coverage gate:** the arm is void unless it returns exactly 564 unique qids
with exit status 0.

## Predictions, recorded in advance

- Directional prediction: fused > stem, consistent with 600 s.
- The 600 s effect for OMP specifically was +2.91 (p=.134, n=412) — already
  NOT significant on its own at 600 s. With n=564 and a similar effect size,
  this arm is **not** well powered to detect a ~3 point shift either. We are
  therefore testing REPLICATION OF DIRECTION AND MAGNITUDE, not significance.
  A non-significant positive result of similar magnitude counts as consistent;
  a sign reversal or a near-zero point estimate counts as a failure to replicate.

## What each outcome does to the paper

- **Replicates (positive, similar magnitude):** the prompt-boundary claim may be
  stated for both long bins, still as a level shift and still with the caveat
  that the mechanism is unidentified (three mechanism tests were negative on
  2026-08-22).
- **Fails to replicate (null or reversal):** the four-point prompt-boundary
  figure stays explicitly labelled LVB-600 s, and the paper says so.

Either way the frame-set overlap between arms is reported as manipulation
evidence that the query change actually moved the selection — never as an outcome.

## Deviations

Any deviation from the above will be recorded in this file with its reason
before the result is reported.
